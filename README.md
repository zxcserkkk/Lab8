# Домашнее задание к работе 8
## Условие задачи
Вычислите с использованием цикла for значение для заданного n
**Вариант 13**

##Алгоритм

**Начало**
-Ввести целое число n.
-Задать начальные значения: s = 0 (сумма), i = 1 (номер слагаемого).
-Пока i ≤ n, повторять:
-вычислить k = 2 * i + 1 (нечётное число для знаменателя);
-прибавить к сумме дробь: s = s + 1.0 / (k * k);
-увеличить i на 1.
-Вывести результат s.
**Конец**

### Блок-схема

## Код

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <locale.h>

int main()
{
    int n, i;
    double s;
    setlocale(LC_ALL, ".UTF-8");
    printf("Введите n: ");
    scanf("%d", &n);
    s = 0;
    for (i = 1; i <= n; i++)
        s += 1.0 / ((2 * i + 1) * (2 * i + 1));
    printf("Результат: %f\n", s);
    return 0;
}
```
